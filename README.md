
# 🌿 EcoLife - Environmental Awareness Website

## About the Project
EcoLife is an environmental awareness website that promotes nature protection and sustainability. It encourages people to help the environment through simple eco-friendly practices.

## Objectives
- Promote environmental awareness.
- Encourage recycling and waste reduction.
- Inspire people to plant trees and save water.
- Support a cleaner and greener future.

## Website Pages
- **Home** – Introduction to EcoLife and environmental awareness.
- **About** – Mission and vision of EcoLife.
- **Gallery** – Images of beautiful nature and landscapes.

## Technologies Used
- HTML5
- CSS3

## Features
- Simple and clean design.
- Green environmental theme.
- Navigation between pages.
- Nature image gallery.
- Responsive image sizing.
